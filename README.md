# CSS Chessboard

##  About the Project
A simple Chessboard layout built using HTML5 and CSS3, focusing on CSS Grid and Flexbox concepts. This project helped me practice rows, columns, alignment, and creating structured web layouts.

##  Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox

## Features
- Classic chessboard layout
- Alternating black and white squares
- Structured rows and columns
- Clean and simple design

## What I Learned
- Understanding CSS Grid and Flexbox
- Working with rows and columns
- Practicing alignment and spacing
- Creating layouts using CSS

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

This is one of my frontend practice projects as I continue strengthening my HTML and CSS fundamentals.
